# AIGC· 顺德区博物馆 — AI生成宣传视频

## 一、单位信息

| 单位名称 | 佛山市顺德区博物馆 |
| --- | --- |
| 所属领域 | 文物收藏、展示与保护 |
| 目标受众 | 社会公众、游客、文博爱好者 |

## 二、赛题信息

| 赛题名称 | AI生成一个顺德区博物馆宣传视频 |
| --- | --- |
| 命题阐述 | 利用馆藏文物、相关展品等元素，通过AI策划生成一条博物馆宣传视频，发布在博物馆官方账号和顺德官方媒体账号，为博物馆引流，扩大知名度和影响力。 |
| 当前痛点 | 进馆人流量不高；现有宣传视频均为人工拍摄，时间及人力成本较高。 |

## 三、任务与交付

- 任务产出：利用AI策划并生成一条以馆藏文物、展品为核心元素的宣传视频。
- 交付物：AIGC图片/视频/文案。

## 四、评审与对接

- 最低成果：生成一条符合官方发布要求的宣传视频。
- 评审标准：创新性、传播效果。
