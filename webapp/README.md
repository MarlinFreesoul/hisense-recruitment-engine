# Hisense HireAI｜海信招聘运营智能体

顺德 2026 AI 黑客松参赛 MVP。系统围绕制造业招聘，把岗位治理、JD 标准化、人才匹配、结构化 AI 初筛、人工终审和招聘运营看板串成一条可演示闭环。

## 一分钟体验

1. 进入“岗位治理”，选择高风险岗位，查看 OCR 原文、标准画像和合规提示。
2. 点击“人工确认并发布”，完成模拟渠道发布。
3. 进入“人才匹配”，查看候选人的匹配证据与待确认缺口。
4. 进入“AI 初筛”，完成三个结构化问题并提交人工复核。
5. 返回运营驾驶舱，查看招聘漏斗、行动中心和智能体动态。

## 本地运行

需要 Node.js 22.13 或更高版本。安装依赖后运行 `npm run dev`。在不支持 Cloudflare 本地运行时的旧版 macOS 上，可使用支持的 Linux DevContainer；最终构建与部署不受影响。

## 数据与安全边界

- `public/data/hisense_boss_jobs_structured.md` 保存 115 条公开招聘截图的 OCR 结构化结果。
- 演示候选人均为虚构、脱敏数据。
- AI 只辅助判断，不执行自动录用或淘汰。
- 婚育、民族、健康史等非岗位必要信息不进入筛选。
- D1 仅保存工作流和审计记录；无数据库时自动切换为离线演示模式。

详见 `docs/技术与演示手册.md`。
