# HR 工作台 Demo（前端）

海信 AI 招聘智能体的静态前端 demo，展示完整招聘漏斗：岗位需求 → 简历池 → AI 筛选 → Top 候选人 → 面试题 → 人才评价汇总。

## 运行

```bash
# 1. 先启动后端（仓库根目录）
python3 main.py                    # API 服务 → http://localhost:8000

# 2. 启动前端静态服务（本目录）
#    Windows 双击 start_demo.bat，或手动：
python3 -m http.server 8765
```

浏览器打开：**http://127.0.0.1:8765/hr_workbench.html**

> 前端通过 `http://<hostname>:8000/demo_data` 读后端（后端实时读飞书多维表格 + 确定性评分引擎），所以先起后端、再起前端。

## 文件

| 文件 | 说明 |
|---|---|
| `hr_workbench.html` | 主工作台（简历筛选 + 人才评价汇总 + 真实简历投递） |
| `interview_form.html` | H5 面试信息采集表单 |
| `start_demo.bat` | Windows 一键启动静态服务 |
| `data/mock_resume_pool_100.json` | 100 份模拟简历（离线兜底数据） |

## 核心能力

- **确定性评分**：每份简历按岗位族 5 维度加权打分（0-100），每一分追到规则 + 简历原文证据，可复现
- **学历打分化**：学历是打分维度（本科>大专>中专），大专+对口经验补偿，不机械一票否决
- **淘汰信号分级**：重信号（意向不符/薪资超/频繁跳槽/无制造业经验）扣分或淘汰，轻信号（到岗/通勤/薪资略高）待确认
- **真实简历导入**：粘贴非标简历 → LLM 解析结构化 → 写入飞书 → 自动评分 → 刷新可见
- **人才评价汇总**：内部人才库 → 历史候选人复用 → 外招兜底；候选人对比；入库 + offer 递补
