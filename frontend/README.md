# 前端（预留位置）

此目录预留给前端（Web / 飞书应用 / 小程序等）。前端通过 `api/server.py` 暴露的 HTTP 接口调用后端。

## 后端接口（后端启动后访问 `http://<IP>:8000/docs` 看完整文档）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/health` | 健康检查 |
| POST | `/parse_resume` | 简历文本 → 结构化字段（LLM 解析） |
| POST | `/match` | 触发一次匹配评分，写回飞书 |
| GET | `/jobs` | 读招聘需求 |
| GET | `/resumes` | 读简历库 |
| GET | `/results` | 读评分结果 |

## 前端要对接的数据

- 数据源：飞书多维表格（岗位 / 简历 / 评分结果三张表）
- 或者：后端 API（`/jobs`、`/resumes`、`/results`）
- 交互入口：飞书多维表格本身（HR 直接操作），或独立前端页面

## 技术选型建议（可选）

- Web：Vue/React + 飞书多维表格 iframe 嵌入
- 飞书应用：飞书开放平台的「网页应用」或「多维表格插件」
- 轻量演示：直接看飞书多维表格的「评分结果表」即可，无需独立前端
