# Specs — 功能规格目录

按功能编号组织，每个规格一个子目录：

```
specs/
└── ###-feature-name/
    ├── spec.md      # 功能规格（必填）
    ├── plan.md      # 实现计划
    └── tasks.md     # 任务拆解
```

**编号规则**：从 `001` 开始递增。
