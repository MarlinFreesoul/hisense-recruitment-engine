# 提示词 ③:AI 面试辅助节点(岗位模型 + 个性化题库)

> 给:队友 B ｜ 模块③ 面试辅助 ｜ 产出 `src/interview.py`

## 项目背景

海信容声「AI 招聘智能体」黑客松项目。多级漏斗:

```
简历PDF → 解析 → 简历结构化 → ①筛查 → ②风险 → ③面试(你在这) → ④汇总 → 人工终判
```

你的模块是**核心卖点**:瑞幸/北森/达美乐验证过,「AI 面试官」是招聘 AI 里落地最广、ROI 最高的场景。赛题模块③要求「结构化题库 + 针对简历短板定制个性化问题 + 面试纪要 + 打分评级」。

## 你的任务

构建 `src/interview.py`,做**三层**(这是你模块的价值所在,别只做"生成几个问题"):

1. **岗位模型**:每个岗位类型一套结构化考察维度(参考瑞幸/北森)
2. **通用题库**:结构化问题,可复用
3. **个性化问题**:**针对 ① 筛查输出的 `gaps`(短板)定制问题** —— 这是核心

## 输入

简历 JSON(同①)+ ① 筛查输出的 `gaps`:

```json
{
  "resume": {"name": "张三", "education": "硕士", "skills": ["Python", "STM32", "C语言"], "experience_years": 5},
  "gaps": ["缺PCB经验"],
  "jd": {"title": "嵌入式高级软件开发工程师", "soft": ["嵌入式", "制冷", "ARM"]}
}
```

## 输出(你要产出的 JSON)

```json
{
  "general_questions": ["自我介绍", "为什么离开上家", "职业规划"],
  "targeted_questions": [
    {"gap": "缺PCB经验", "question": "这个岗位需要看板卡图,你没列 PCB 经验,如果来了怎么补这块?", "why": "岗位要求 PCB,简历无此技能"}
  ],
  "rubric": [{"dim": "技术匹配", "weight": 0.5}, {"dim": "稳定性", "weight": 0.3}, {"dim": "沟通", "weight": 0.2}]
}
```

## 硬性要求

- **个性化是核心**:`targeted_questions` 必须**针对 `gaps`** 出题,不能是通用题
- **岗位模型**:按岗位类型(技术岗/蓝领岗/职能岗)区分考察维度——技术岗问技能证据,蓝领岗问稳定性/倒班/身体条件,职能岗问流程/协调
- LLM 用 DeepSeek;能模板化的就模板化,别全让 LLM 生成
- 小文件 + 不可变 + 中文注释
- 能独立运行:`python3 src/interview.py`

## 完成标准

- [ ] `python3 src/interview.py` 跑通,输出符合上面的 JSON
- [ ] 至少区分技术岗 / 蓝领岗 两套考察维度
- [ ] `targeted_questions` 确实针对输入的 `gaps` 定制
