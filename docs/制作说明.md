# 海信 AI 招聘智能体 · 制作说明与演示手册

## 一、运行环境

- Python 3.10+（开发用 3.14）
- Node.js 18+（前端 vinext）
- 依赖见 `requirements.txt`（FastAPI、PyMuPDF、cos-python-sdk-v5 等）

## 二、快速开始

### 后端（FastAPI，端口 8000）

```bash
pip install -r requirements.txt
cp .env.example .env        # 填飞书凭证 + DeepSeek key + 腾讯云三件套
python main.py              # 启动 API 服务，访问 http://localhost:8000/docs
```

### 前端（HR 工作台 demo）

```bash
cd demo
python -m http.server 8765   # 访问 http://127.0.0.1:8765/hr_workbench.html
```

> 前端通过 `http://<hostname>:8000/demo_data` 读后端，先起后端再起前端。

### 前端（vinext 工作台，端口 3000）

```bash
cd webapp
npm install
npm run dev -- --hostname 0.0.0.0
```

## 三、配置说明（.env）

| 配置 | 用途 |
|---|---|
| FEISHU_APP_ID / FEISHU_APP_SECRET | 飞书应用凭证 |
| DEEPSEEK_API_KEY | LLM 简历解析 + 面试纪要 |
| TRTC_APP_ID / TRTC_SECRET_KEY | 视频面试房间 |
| TENCENT_SECRET_ID / TENCENT_SECRET_KEY / ASR_APP_ID | 语音识别 |
| COS_BUCKET / COS_REGION | 面试录音存储 |

飞书表格 ID（9 张表）已在 `config.py` 有默认值，换企业时再覆盖。

## 四、现场演示脚本（约 5 分钟）

1. **开场（30s）**：一句话介绍 —— 用确定性可解释评分替代人工主观筛简历。
2. **简历筛选（2min）**：展示 100+ 份简历 → 自动分层（推荐/待确认/不推荐），点开候选人看「每一分追到简历原文」的证据。
3. **真实简历导入（1min）**：粘贴一份非标简历 → LLM 解析 → 自动评分 → 刷新可见，证明真实简历能真实筛选。
4. **人才评价汇总（1min）**：内部人才库 → 历史复用 → 外招兜底；候选人对比；offer 递补。
5. **收尾（30s）**：技术架构 + 亮点总结。

## 五、部署说明

1. 后端：`python main.py`（或 uvicorn），配 nginx 反代 + HTTPS。
2. 前端 demo：静态文件放 nginx，指向后端 8000。
3. 视频面试：需腾讯云 TRTC/ASR/COS 凭证，凭证为空时优雅降级（不崩溃）。
