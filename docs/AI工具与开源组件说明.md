# AI 工具、模型、素材及开源组件说明

## 一、AI 工具 / 模型

- **DeepSeek-chat（V3.2）**，版本 `deepseek-chat`。主要用途：① 把非标简历（口语化、字段缺失）用 LLM 解析成结构化字段；② 把线上面试对话自动梳理成纪要。来源为 DeepSeek 官方 API（api.deepseek.com）。

说明：评分引擎、淘汰信号分级、学历打分化、风险识别均为自研确定性规则算法，不调用 LLM——同一份简历在任何机器跑出同一分数，每一分追得到规则行和简历原文证据。LLM 只用于语义判断（简历结构化、面试纪要），纯规则一律用确定性函数。

## 二、外部数据 / 素材来源

- 招聘岗位调研数据：来源为 BOSS 直聘 115 条、51job 308 条、校招岗样本，合计 423 条，用于构建 6 大岗位族 JD 模板、匹配权重、技能模型。
- 简历样本：自建 mock 数据，共 101 份，用于 Demo 演示与评分引擎验证。
- 图片、音乐、视频素材：无。
- 字体：系统自带 PingFang SC、STHeiti，用于演示材料 PDF 渲染。
- 第三方付费素材：无。
