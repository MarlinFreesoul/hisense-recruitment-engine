# 海信 AI 招聘智能体 · 招聘漏斗系统说明

> 版本 v1.0 · 2026-08-15

## 一、系统定位

海信容声（广东）冰箱的 AI 招聘智能体，把「JD 发布 → 100 份简历 → 筛出 Top10 面试名单」的完整招聘漏斗，用**确定性规则 + 可解释评分**自动化。核心价值不是替 HR 做最终录用决定，而是：

1. 把 100 份简历**快速分层**（推荐 / 待确认 / 不推荐）。
2. 让 HR 知道**为什么**推荐、为什么待确认、为什么不推荐。
3. 把短板转成**面试追问**，把风险转成**核验动作**。
4. 让用人部门看到**证据**，而不是只看到一个分数。

## 二、招聘漏斗（完整链路）

```
① JD 发布（飞书招聘需求表）
   ↓
② 简历收集（飞书数据表，简历结构化 LLM 提取）
   ↓
③ 简历筛选（硬条件门槛 + 软条件 5 维度加权 = 匹配度 0-100）
   ↓
④ 风险识别（证书/断层/跳槽/期望错位，带核验动作）
   ↓
⑤ 推送用人部门（匹配度 + 证据 + 风险，人工选择通过/不通过）
   ↓
⑥ 面试辅助（结构化核心问题采集 + 面试题 + 为什么问/期望/风险信号）
   ↓
⑦ 人才评价（候选人对比 + 入库标签 + 招聘进度跟踪）
   ↓
⑧ 选人决策（offer → 放弃则推备选）
```

## 四、评分系统

### 4.1 两层结构

| 层 | 作用 | 判定 |
|---|---|---|
| 硬条件（门槛） | 一票否决 | 布尔规则（学历/专业/倒班/到岗） |
| 软条件（加权） | 匹配度 0-100 | 评分函数 × 权重 |

### 4.2 软条件维度与权重（对齐陈老师评分标准）

**装配工（一线生产）**：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 到岗工期 | 25 | 是否随时/1周内到岗 |
| 倒班接受 | 20 | 是否接受倒班/站班/加班 |
| 制造业经验 | 20 | 是否做过装配/包装/质检/搬运 |
| 稳定性 | 20 | 工作持续时间、跳槽频率 |
| 现场适配 | 15 | 5S/安全/质量意识/班组协作 |

**精益物流（采购物流）**：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 专业经验 | 20 | 物流/工业工程/供应链 |
| 沟通协同 | 25 | 跨部门协作 |
| 数据整理 | 20 | ERP/WMS/Excel/SAP |
| 流程意识 | 20 | 5S/精益改善/价值流 |
| 稳定落地 | 15 | 项目落地/稳定性 |

### 4.3 三态评分

每个维度返回：满足 / 不满足 / 未知（字段缺失）。

- 满足 → 评分函数给分
- 不满足 → 低分（扣分）
- 未知 → 中性分（5分），不误杀信息缺失的候选人

### 4.4 推荐等级（对齐陈老师标准）

| 分数 | 状态 | 下一步动作 |
|---|---|---|
| 90-100 | 推荐 | 立即约面 |
| 80-89 | 推荐 | 电话确认后约面 |
| 75-79 | 推荐 | 加入备选 |
| 45-74 | 待确认 | 电话确认 |
| 0-44 | 不推荐 | 暂不推进 |

### 4.5 匹配度分级（对照学术标准）

| 匹配度 | 等级 | 人才分级 |
|---|---|---|
| 81-100 | 完全匹配 | A级 |
| 61-80 | 基本匹配 | B级 |
| 41-60 | 相当匹配 | B/C级 |
| 21-40 | 不匹配 | C级 |
| 1-20 | 非常不匹配 | 不录用 |

## 五、可解释性

1. 每个分数 → 追到评分函数规则行
2. 每个结论 → 追到维度证据（简历原文片段）
3. 每条风险 → 带核验动作（如「请核验证书原件与有效期」）
4. 权重变更 → 飞书留痕，实时生效


## 七、快速开始

```bash
# 后端
pip install -r requirements.txt
cp .env.example .env   # 填飞书凭证 + DeepSeek key
python main.py         # 启动 API 服务 → http://localhost:8000/docs

# 前端（vinext）
cd webapp && npm install
npm run dev -- --hostname 0.0.0.0   # → http://localhost:3000
```

| 面试采集表 | H5 表单回复 |
| 面试记录表 | 面试题 + 面试阶段 |
