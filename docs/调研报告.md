# 海信容声（广东）冰箱有限公司近 3 年招聘岗位调研报告

> 版本 v1.0 · 2026-08-15 · 用于生成 JD 的数据底座

## 一、调研目标与范围

回答四个问题：

1. 近 3 年公开招聘岗位有哪些类型？
2. 校招 / 社招 / 一线用工分别在招什么？
3. 岗位需求变化给 AI 招聘智能体 Demo 带来什么启发？
4. 当前公开数据缺什么，哪些结论只能作推断？

**范围**：以海信容声（广东）冰箱（顺德制造基地）为主，海信集团校招层为参照。

## 三、方法论（双向锚定）

核心原则：**每个匹配维度必须回溯到简历真实字段或可观测代理**。

- 简历里有真实字段的（年龄/学历/专业/经验/技能/证书）→ 进快速筛选；
- 简历里只有代理指标的（跳槽频率→稳定性、到岗时间→意愿、自我评价关键词→特质）→ 用可观测代理推断；
- 简历里完全没有的（动机/健康/技能真实性）→ 移出快速筛选，交给面试 STAR / 背调 / 体检。

## 七、近 3 年趋势

1. **从「生产管培」到「制造运营专业岗位拆分」**：2024 届主招「生产管培生 30 人」，2026 届拆成现场工艺、IE、质量、设备、采购、仓储物流、计划管理等专业岗。
2. **一线用工长期高频**：BOSS 端 51.3% 普工 + 33.9% 临时工/小时工，核心要求是到岗快、稳定、接受倒班、基础合规。
3. **校招岗位集中服务「现场效率、质量、供应链」**。
4. **薪酬分层清晰**：一线 5-7K / 大专技能 4.5-5.5K / 本科校招 7-11K / 社招资深 12K+。

## 八、数据缺口（诚实标注）

1. 官方招聘后台的岗位历史数据（发布时间/下线时间/投递量/初筛通过率）。
2. 面试通过率、Offer 接受率、入职率、试用期留存率。
3. 劳务派遣 / 直招 / 校招岗位的区分字段。
4. 淡旺季用工量变化、HR 对岗位紧急度和筛选难点的标注。

**没有这些数据，本报告结论是「公开岗位样本调研 + 合理推断」，不是企业内部招聘全貌。评分权重的最终校准，需要 HR 用真实批量简历 + 录用标注反哺。**

## 九、对 Demo 的直接建议

第一版不做「简历筛选器」，做「制造业招聘工作台」：

1. **岗位库**：展示 2024-2026 岗位族变化。
2. **JD 标准化**：把重复一线岗位合并为标准 JD（岗位去重聚类是刚需）。
3. **候选人筛选**：一线/专业岗两套评分规则。
4. **风险预警**：按岗位族输出核验点。
5. **面试题库**：按岗位族生成结构化追问（5 类，见 `interview_question_bank.json`）。
6. **数据看板**：岗位类型分布、薪资层级、学历/经验要求、福利标签。

**差异化表达**：不是通用 HR SaaS，而是把海信容声真实招聘岗位沉淀成制造业招聘知识库，让 HR 在重复岗位筛选和面试题准备上显著降本增效。
