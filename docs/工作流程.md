# 海信 AI 招聘智能体 · 工作流程

## 一、招聘漏斗（完整闭环）

```
① JD 发布（飞书招聘需求表，支持自动生成 JD）
   ↓
② 简历收集（真实简历导入 → LLM 解析结构化 → 写飞书简历库）
   ↓
③ 简历筛选（硬条件 + 软条件 5 维度加权 + 淘汰信号 → 匹配度 0-100）
   ↓
④ 风险识别（证书/断层/跳槽/造假/技能真实性，带核验动作）
   ↓
⑤ 推送用人部门（匹配度 + 证据 + 风险，人工选择通过/不通过）
   ↓
⑥ 面试辅助（结构化面试题 + 视频面试 + 面试纪要 + 面试后评分）
   ↓
⑦ 人才评价（内部人才库 → 历史复用 → 候选人对比 → 入库 → offer 递补）
   ↓
⑧ 选人决策（offer → 放弃则推备选）
```

## 二、简历筛选流程（核心）

1. **岗位族匹配**：岗位名 → 6 大岗位族（一线生产/现场管理/工艺设备/质量/采购物流/研发工程）。
2. **硬条件门槛**：只有「求职意向不符」「明确不接受倒班」这类硬伤一票否决。
3. **软条件打分**：按岗位族 5 维度加权（学历/专业经验/沟通协同/数据整理/流程意识/稳定落地等），每个维度 0-10 分，归一化到 0-100。
4. **学历打分化**：本科 > 大专 > 中专 > 高中 > 初中，大专 + 对口经验补偿。
5. **淘汰信号分级**：重信号扣分或淘汰，轻信号待确认。
6. **推荐分级**：推荐（80+）/ 待确认（45-79）/ 不推荐（0-44），每档给出下一步动作。

## 三、真实简历导入流程

```
粘贴/上传非标简历
  → LLM 解析（姓名/学历/专业/年限/技能/证书/自我评价/到岗）
  → 写飞书简历库（绑定应聘岗位）
  → 确定性评分引擎打分
  → 返回匹配度 + 推荐等级 + 可解释证据
  → 前端刷新，新候选人出现在筛选结果
```

## 四、面试辅助流程

1. **面试题生成**：按岗位族题库 + 简历短板/风险点定向追问，每道题带「为什么问/期望信号/风险信号」。
2. **视频面试**：TRTC 房间 + ASR 实时转写 + COS 录制。
3. **面试纪要**：线上面试对话 LLM 梳理纪要 + 评分评级（A/B/C/备选/暂缓）。
4. **面试后评分**：五维度 competency_scores 求和 → 面试总分 → 面试评级。

## 五、人才评价汇总流程（模块 4）

1. **人才来源优先级**：先内部人才库（可调岗）→ 历史候选人（曾面试/曾 offer）→ 外招兜底。
2. **候选人对比**：按岗位取 top 候选人，横向对比匹配分/风险/面试重点。
3. **入库**：合格候选人（面试评级 A/B/C/备选）自动入库。
4. **offer 递补**：候选人放弃 offer 时，按（评级优先级/面试分/匹配分）排序递补。

## 六、数据流

```
飞书多维表格（岗位/简历/权重）
   ↓ 后端实时读取
确定性评分引擎（硬条件 + 软条件 + 淘汰信号）
   ↓ 产出结构化评分
飞书评分结果表 + 面试记录表 + 人才库
   ↓ 前端实时同步
HR 工作台 / vinext 前端展示
```
