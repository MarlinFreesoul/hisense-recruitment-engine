# 海信容声 AI 招聘智能体 · 架构与优先级

> 版本 0.1 · 定稿 2026-08-15 · 依据:赛题原文 + 瑞幸/北森/海纳案例 + 开源调研

## 一、产品定位

一个「从简历到面试」的招聘筛选闭环:

> 一份简历进来 → AI 筛查(可解释匹配)→ 识别短板 → 自动生成针对性面试题 → 人工终判

## 二、经过验证的架构:多级漏斗

```
简历PDF → 解析 → 硬条件过滤(规则,免费) → 软条件匹配(LLM+证据) → AI面试(结构化题库+个性化) → 人工终判 → 人才库标注
```

**三条被验证的原则**(每条都有案例背书):

1. **岗位模型驱动** — 瑞幸/北森:每个岗位类型一套结构化评估维度 → 解决「标准不统一 / 匹配主观化」
2. **漏斗分层控成本** — candisift:确定性过滤 → embedding → LLM → 解决「筛选效率低」
3. **人机协同** — 瑞幸:AI 评分 + 人工复核 → 合规 + 解决「复盘成本高」

**案例数据**:

| 案例 | 数据 |
|---|---|
| 瑞幸 AI 面试(2021 起) | 通过率 30-40%,招聘周期 7天→3天,离职率 -12% |
| 北森 AI 闪面(国家专利) | 每分钟 5-10 人,效率 5-10 倍,近千家 |
| 海纳×达美乐 | 千店扩张靠 AI 面试撑高并发 |
| 海信现状 | 赛题原文:内部系统 + **北森** 完成全流程招聘 |

## 三、优先级(P0 → P3)

| 优先级 | 模块 | 定位 | 深度 |
|---|---|---|---|
| **P0** | 简历筛查(可解释匹配) | 入口 + 第一痛点(效率低/主观化) | 深入 |
| **P1** | AI 面试辅助(岗位模型 + 个性化题库) | 核心卖点(瑞幸/北森验证的最高 ROI) | 深入 |
| P2 | 风险识别 | 差异化点缀(合规/造假/提示词注入) | 轻 |
| P3 | 人才库 + 标注 | 数据沉淀基础设施(双库+碰撞) | 支撑 |

## 四、本次聚焦:「简历 → 面试」闭环

核心叙事:**简历筛查的输出(硬软匹配 + 短板)→ 喂给面试辅助(针对性出题)**。

- **P0 深入 = 可解释匹配,不是黑箱分数**:
  硬条件逐条 check(确定性)+ 软条件评分 + 证据 → 输出「理由 + 短板」,而非一个 0-100 数字
  (教训:HackerRank 同一简历评分 66~99 波动,纯 LLM 打分不可靠)
- **P1 深入 = 岗位模型 + 通用题库 + 个性化问题**(针对简历短板定制)
