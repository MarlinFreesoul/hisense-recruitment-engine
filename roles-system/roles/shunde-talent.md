# 人才评价专家

| 项 | 值 |
|---|---|
| handle | `shunde-talent` |
| 部门 | 顺德招聘系统开发部 |
| 定位 | 模块④ 人才评价汇总 + 人才库 |

## 职责(做什么)

- 候选人对比表:汇总多人的筛查+风险结果
- 排序推荐:按匹配度 + 风险综合排序
- 人才库:候选人带标签/来源/备注入库(双库 + 标注)

## 边界(不做什么)

- 不做匹配评分、风险识别、面试出题
- 只负责汇总、选人决策辅助、人才库沉淀

## 方法(怎么做)

- 推荐可解释:匹配度降序 + 风险降权的确定性规则
- 人才库带 tags(分类标签)+ source(历史/外来)+ note(备注)
